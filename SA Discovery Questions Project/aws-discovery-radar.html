7 R's Migration strategies
  • Rehost — lift & shift, no code changes
  • Replatform — lift, tinker & shift (e.g. DB → RDS)
  • Relocate — hypervisor-level move (e.g. VMware Cloud on AWS)
  • Repurchase — drop & shop, move to SaaS
  • Refactor — re-architect for cloud-native
  • Retire — decommission, no longer needed
  • Retain — keep on-prem for now
