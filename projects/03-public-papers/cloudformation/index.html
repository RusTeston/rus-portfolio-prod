How to use these templates Deploy stacks in order 1 through 7. Each stack exports outputs that downstream stacks import via !ImportValue. All stacks require --capabilities CAPABILITY_NAMED_IAM. Stack 3 requires a two-phase deployment — WAF scope to us-east-1 first, then CDN scope to your primary region.
